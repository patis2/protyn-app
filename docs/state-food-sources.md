# State food sources

Protyn plans meals from the state a person cooks from. This file lists each state's dishes, where the dishes were checked, and what was left out because it could not be confirmed. Protein numbers are estimates for the stated portion and still need a registered dietitian's review. When a dish is paired with a side, such as "with dal" or "with curd", the side is Protyn's suggestion for more protein. It is not part of the traditional dish.

When a state's own dishes can't fill a meal under someone's filters (for example a vegetarian in a state whose traditional breakfasts are mostly non-vegetarian), Protyn borrows from the same region first, then the nearest region. The recipe's "why this" note says when that happens.

## Left out because I couldn't confirm them

- **Hyderabadi haleem (Telangana):** it's widely known, but the Telangana cuisine source I used doesn't list it. It also needs specific cooking that a weekly plan doesn't fit well.
- **Akki rotti (Karnataka):** not named in the source.
- **Goan tonak and chonak recheado:** not named in the source.
- **Champaran "ahuna" mutton (Bihar):** the source names a Champaran grilled mutton called taash, not ahuna, so I left both out until a better source is found.
- **Bedmi puri and nimona (Uttar Pradesh):** not named in the Wikipedia page used.

## Still to review

- Pairing notes: the Maharashtra source names Kolhapur's spicy red curry (tambda rassa) rather than a "Kolhapuri chicken" dish, so Protyn's chicken sukka with bhakri follows that style. In Bengal the fish curry is often called macher jhol or jhal, and Protyn uses the Odia name machha jhola for both states.

- Everyday dishes marked as cooked across India (for example omelette, roasted chana, khichdi, egg curry, chicken curry) are tagged for every state.
- Some states have only a few vegetarian breakfasts of their own: Andaman and Nicobar, Arunachal Pradesh, Assam, Goa, Jammu and Kashmir, Ladakh, Lakshadweep, Manipur, Meghalaya, Mizoram, Nagaland, Sikkim, Tripura and Uttarakhand. For a vegetarian in these places, breakfast, and in a few cases lunch, borrows from the nearest region.
- A local cook or dietitian from each state should review the list before launch.
